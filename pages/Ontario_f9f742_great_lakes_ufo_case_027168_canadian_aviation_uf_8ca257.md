## Introduction

For [Ontario]({{ 'what-does-ontarios-ufo-record-really/' | relative_url }})'s [Great Lakes]({{ 'great-lakes/' | relative_url }}) sightings, official Canadian aviation records can establish far less—and far more—than many people assume. They can often confirm that a pilot, controller or flight crew reported an unusual object, that the report affected aircraft operations, and which organisations became involved. What they usually cannot do is identify the object with certainty. That is because Canada's aviation reporting system is designed to support flight safety, not to investigate unexplained aerial phenomena. The result is a paper trail that is highly valuable for verifying that an event occurred, but often incomplete when readers want a final explanation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://tc.canada.ca/en/aviation/aviation-publications/civil-aviation-daily-occurrence-reporting-system-cadors-manual-tp-4044" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tc.canada.ca">[tc.canada.ca]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tc.canada.ca</span><span class="citation-popover-title">Civil Aviation Daily Occurrence Reporting System (CADORS) Manual</span><span class="citation-popover-snippet">TP 4044September 5, 2025...</span><span class="citation-popover-meta">Published: September 5, 2025</span></span></span>

For reports over the Great Lakes, this limitation is especially important. Flights routinely cross Canadian and United States airspace, while civil aviation, military surveillance and accident investigation are divided between several organisations. Understanding what each record actually proves is therefore more useful than treating any single document as definitive evidence.

## What CADORS records about aviation incidents

The Civil Aviation Daily Occurrence Reporting System (CADORS) is Transport Canada's central database for civil aviation occurrences. It was created to provide rapid reporting of aviation events and today captures thousands of incidents every year from air traffic service providers and other reporting sources. Its purpose is operational awareness and aviation safety rather than determining the true nature of every reported object.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://tc.canada.ca/en/aviation/publications/aviation-safety-letter/issue-2-2021/civil-aviation-daily-occurrence-reporting-system-cadors" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tc.canada.ca">[tc.canada.ca]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tc.canada.ca</span><span class="citation-popover-title">The Civil Aviation Daily Occurrence Reporting System (CADORS</span><span class="citation-popover-snippet">July 15, 2021...</span><span class="citation-popover-meta">Published: July 15, 2021</span></span></span>

For Ontario UFO-related reports, a CADORS entry can reliably establish facts such as:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* the date and approximate time of the occurrence;
* the reporting aircraft or facility;
* the general location;
* whether pilots or controllers described an unidentified object or light;
* whether the report affected flight operations, such as a course change or increased vigilance;
* whether the event was passed to another authority through standard reporting channels.

</div>

Those points matter because they distinguish documented aviation occurrences from later retellings. A CADORS record confirms that an aviation report entered the official safety system, not merely that someone later claimed an unusual encounter.

Equally important is what CADORS does **not** prove. A narrative describing an unidentified object is generally a summary of the initial report. It is not a technical conclusion that an unknown craft was present, nor does the inclusion of a report imply government endorsement of the witness's interpretation. The database contains many different categories of aviation occurrences, including reports involving balloons, meteors, rockets and unidentified objects, because all may be relevant to operational safety when first observed.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://tc.canada.ca/en/aviation/publications/aviation-safety-letter/issue-2-2021/civil-aviation-daily-occurrence-reporting-system-cadors" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tc.canada.ca">[tc.canada.ca]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tc.canada.ca</span><span class="citation-popover-title">The Civil Aviation Daily Occurrence Reporting System (CADORS</span><span class="citation-popover-snippet">July 15, 2021...</span><span class="citation-popover-meta">Published: July 15, 2021</span></span></span>

## Why occurrence reports are not full investigations

One of the most common misunderstandings is treating a CADORS entry as if it were an investigative report. It is not.

Transport Canada's occurrence reporting system is intended to record that something happened and distribute timely safety information. Whether a detailed investigation follows depends on other organisations and on the significance of the event.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://tc.canada.ca/en/aviation/aviation-publications/civil-aviation-daily-occurrence-reporting-system-cadors-manual-tp-4044" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tc.canada.ca">[tc.canada.ca]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tc.canada.ca</span><span class="citation-popover-title">Civil Aviation Daily Occurrence Reporting System (CADORS) Manual</span><span class="citation-popover-snippet">TP 4044September 5, 2025...</span><span class="citation-popover-meta">Published: September 5, 2025</span></span></span>

In Canada, the Transportation Safety Board (TSB) independently decides whether a reported occurrence deserves a formal investigation. Most reported aviation events are never examined in depth because the Board concentrates its resources on cases most likely to improve transportation safety. Thousands of occurrences are reported annually, but only a small proportion become full investigations.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.tsb.gc.ca/eng/lois-acts/evenements-occurrences.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tsb.gc.ca">[tsb.gc.ca]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tsb.gc.ca</span><span class="citation-popover-title">Policy on Occurrence Classification</span><span class="citation-popover-snippet">Transportation Safety Board of CanadaApril 5, 2023...</span><span class="citation-popover-meta">Published: April 5, 2023</span></span></span>

This distinction explains why readers sometimes encounter a brief CADORS entry with no obvious conclusion. An occurrence may have:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* been recorded only for situational awareness;
* required no further investigation because no safety lessons emerged;
* fallen below the threshold for a formal TSB inquiry; or
* been examined through operational channels whose records are held elsewhere.

</div>

The absence of a detailed public report therefore should not be interpreted either as evidence of a cover-up or as proof that nothing unusual occurred. More often, it reflects how Canada's transportation safety system prioritises investigative resources.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.tsb.gc.ca/eng/lois-acts/evenements-occurrences.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tsb.gc.ca">[tsb.gc.ca]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tsb.gc.ca</span><span class="citation-popover-title">Policy on Occurrence Classification</span><span class="citation-popover-snippet">Transportation Safety Board of CanadaApril 5, 2023...</span><span class="citation-popover-meta">Published: April 5, 2023</span></span></span>

## How cross-border agencies divide the evidence

Great Lakes incidents frequently involve fragmented evidence because responsibility is divided between Canadian and American organisations.

A single report may involve several different record holders:


<div class="content-enhancement content-enhancement--benefit" markdown="1">

* **Transport Canada** maintains the CADORS occurrence record for civil aviation reporting.
* **NAV CANADA** manages Canadian civil air traffic services and operational records relating to aircraft movements and controller communications.
* **The Transportation Safety Board** independently investigates only selected occurrences where transportation safety may benefit.
* **NORAD** monitors North American aerospace warning and defence but does not automatically release operational information associated with every reported unidentified object.
* **United States agencies**, including the Federal Aviation Administration (FAA) and, where appropriate, the National Transportation Safety Board (NTSB), may hold records if the event crossed the international boundary or involved American aircraft or airspace.

</div>

Because these organisations serve different legal and operational purposes, no single public file normally contains every radar return, controller conversation, military assessment and investigative conclusion.

For sightings over Lake Ontario, Lake Erie or the upper Great Lakes, an aircraft may depart one country, be controlled by another air navigation provider and operate near airspace monitored by military systems shared through NORAD. The documentary record is therefore naturally distributed across multiple institutions rather than deliberately fragmented.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.tsb.gc.ca/eng/qui-about/enq-inv.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tsb.gc.ca">[tsb.gc.ca]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tsb.gc.ca</span><span class="citation-popover-title">About investigations</span><span class="citation-popover-snippet">Transportation Safety Board of Canada...</span></span></span>

## What the records can prove—and what they cannot

When evaluating an Ontario aviation-related UFO report, official documentation provides several levels of confidence.

Official records can often prove:


<div class="content-enhancement content-enhancement--decision" markdown="1">

* that a report was genuinely made by aviation personnel;
* that the report entered recognised aviation reporting systems;
* that flight crews or controllers regarded the event seriously enough to document it;
* that an occurrence affected aviation safety or operational decision-making.

</div>

Official records usually cannot prove:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* the physical identity of the reported object;
* whether radar definitely detected the same object seen visually;
* whether multiple witnesses observed the identical target;
* whether the object represented an aircraft, atmospheric phenomenon, astronomical object or something genuinely unidentified.

</div>

This distinction is especially important when discussing well-known Great Lakes cases. An occurrence may remain officially "unidentified" simply because the available evidence was insufficient for positive identification. In aviation terminology, "unidentified" generally reflects the limits of the evidence rather than confirmation of an extraordinary explanation.

## Why these records still matter for Ontario's UFO history

Despite their limitations, Canadian aviation records remain among the strongest documentary sources for Ontario's aviation-related UFO history because they originate within operational systems rather than later recollections.

They allow researchers to separate events that demonstrably affected aviation from reports that exist only through media coverage or anecdotal accounts. They also reveal how Canadian authorities prioritise aviation safety over explaining every unusual sighting, providing an important reality check when interpreting Great Lakes incidents.

For readers following Ontario's broader history of UFO reports, the most reliable approach is to treat CADORS, TSB material and related aviation records as evidence of what aviation professionals observed and how institutions responded. They are essential for establishing chronology, operational impact and official handling—but, on their own, they rarely provide the final answer to what was seen.

    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
