## Introduction

One reason lights reported over [Nunavut]({{ 'what-really-lies-behind-nunavuts-ufo/' | relative_url }}) can appear extraordinary is that the Arctic often removes the visual clues people normally use to judge distance, size and speed. A bright light seen above dark, snow-covered terrain may seem surprisingly close, accelerate dramatically or pace an aircraft even when its actual motion is ordinary. These effects do not require unusual atmospheric phenomena or unreliable witnesses. They arise because the human visual system estimates distance by comparing an object with landmarks, horizons, shadows and other reference points—features that are frequently absent during long Arctic nights. Aviation safety organisations in Canada and internationally treat these as well-established visual illusions because they have affected experienced pilots as well as members of the public.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://skybrary.aero/index.php/articles/visual-illusions" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: skybrary.aero">[skybrary.aero]</a><span class="citation-popover" role="note"><span class="citation-popover-source">skybrary.aero</span><span class="citation-popover-title">Visual Illusions &#124; SKYbrary Aviation Safety</span><span class="citation-popover-snippet">Visual Illusions &#124; SKYbrary Aviation Safety...</span></span></span>

## Missing visual references make distance guesses unreliable

In most landscapes the brain constantly compares an object against familiar features such as trees, buildings, roads or hills. Those comparisons help answer simple questions: How far away is it? How large is it? Is it moving quickly?

Large parts of Nunavut provide very few of these cues. Winter darkness, frozen sea ice, snow-covered ground and sparsely populated terrain can leave an observer looking at a single bright point against an almost empty background. Without nearby objects for comparison, it becomes remarkably difficult to judge whether a light is a few hundred metres away or many kilometres distant.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.tsb.gc.ca/eng/rapports-reports/aviation/2019/a19o0178/a19o0178.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tsb.gc.ca">[Transportation Safety Board of Canada]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tsb.gc.ca</span><span class="citation-popover-snippet">Transportation Safety Board of CanadaAir transportation safety investigation report A19O0178 - Transportation Safety Board of Canada...</span></span></span>

This uncertainty has an important consequence. Because apparent speed depends heavily on perceived distance, an incorrect estimate of range also produces an incorrect estimate of velocity. A distant aircraft or celestial object may therefore seem to cross the sky with startling speed, while a nearby object moving at the same angular rate would appear much slower.

The same lack of visual structure is recognised in Canadian aviation guidance as a contributor to the "black hole" illusion, where pilots operating over dark, featureless terrain lose reliable depth perception and can misjudge height and distance. Although that guidance is written for flight safety rather than UFO investigations, it demonstrates how profoundly empty visual environments affect human judgement.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://tc.canada.ca/en/aviation/reference-centre/advisory-circulars/advisory-circular-ac-no" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tc.canada.ca">[canada.ca]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tc.canada.ca</span><span class="citation-popover-title">advisory circular ac no</span><span class="citation-popover-snippet">Transport CanadaAdvisory Circular (AC) No. 603-001March 31, 2020...</span><span class="citation-popover-meta">Published: March 31, 2020</span></span></span>

## How movement of the observer creates apparent movement

Another source of confusion is parallax—the apparent shift in an object's position when the observer moves.

During flights across Nunavut, an aircraft may be turning, climbing or changing heading while the crew watches a bright light through a side window or windscreen. Nearby objects shift rapidly against the background, while distant objects move much less. If the true distance of the light is unknown, the observer can struggle to separate the aircraft's own motion from that of the object being watched.

This is particularly relevant when watching a single isolated light for an extended period. Even small changes in the aircraft's course can make the light appear to drift, follow the aircraft or change direction. If the light is actually a distant star, planet or aircraft, its apparent motion may reflect the observer's changing viewpoint rather than any manoeuvre by the light itself. [Autokinesis]({{ 'autokinesis/' | relative_url }})—the illusion that a stationary light is moving after prolonged fixation—can reinforce this impression.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://skybrary.aero/index.php/articles/autokinetic-effect" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: skybrary.aero">[Skybrary]</a><span class="citation-popover" role="note"><span class="citation-popover-source">skybrary.aero</span><span class="citation-popover-title">Autokinetic Effect &#124; SKYbrary Aviation Safety</span><span class="citation-popover-snippet">Autokinetic Effect &#124; SKYbrary Aviation Safety...</span></span></span>

For this reason, aviation investigators are cautious about treating perceived motion alone as evidence that an unidentified light executed unusual flight characteristics.

## Why lights often seem larger, faster or closer

A point of light carries surprisingly little information about its physical size. Two very different objects can produce almost identical visual impressions if their brightness happens to be similar.

For example:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* A bright planet can appear comparable in size to a distant aircraft light.
* A powerful aircraft landing light viewed head-on can look much larger than its true physical dimensions.
* A distant object crossing the observer's line of sight can appear to cover enormous distances because its true range has been underestimated.

</div>

These errors combine easily. If a witness assumes the light is nearby, its apparent motion implies extraordinary speed. If it is actually tens or hundreds of kilometres away, the same observed angular movement may be entirely ordinary.

This explains why eyewitness descriptions sometimes include statements such as "it shot across the sky" or "it was keeping pace with us". Such descriptions reflect the witness's visual experience, but not necessarily the object's measurable motion.

## Why Nunavut is especially vulnerable to these illusions

The same visual illusion can occur anywhere, but several characteristics of Nunavut make it more common than in densely populated southern regions.

* **Very sparse lighting:** Outside communities, there are few permanent ground lights to provide scale.
* **Featureless snow and sea ice:** Uniform surfaces reduce contrast and remove familiar landmarks.
* **Long periods of darkness:** Extended winter nights increase opportunities for observing isolated lights.
* **Long aviation routes:** Flights often spend lengthy periods over terrain offering almost no external visual references.
* **Exceptionally clear air:** Under favourable conditions, distant lights remain visible for much longer than observers may expect, encouraging overestimates of their proximity.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/earth/earth-observatory/nighttime-lights-reveal-industrial-activity-in-the-arctic-153659/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[nasa.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science Nighttime Lights Reveal Industrial Activity in the Arctic</span><span class="citation-popover-snippet">NASA ScienceNighttime Lights Reveal Industrial Activity in the Arctic - NASA ScienceDecember 9, 2024...</span><span class="citation-popover-meta">Published: December 9, 2024</span></span></span>

These factors do not create false sightings by themselves. Instead, they make otherwise ordinary lights more difficult to interpret accurately.

## What this means for interpreting UFO reports

Distance and speed estimates are often among the least reliable parts of a night-time UFO report from remote Arctic environments. This does not mean witnesses fabricated what they saw. It means the human visual system was working with unusually little information.

Investigators therefore place greater weight on evidence that can independently establish range or motion, such as simultaneous observations from multiple locations, radar data, instrument recordings or photographs that allow geometric analysis. Where those forms of evidence are absent—as is true for many Nunavut sightings—claims about remarkable acceleration or impossible speed should be treated cautiously because they may depend on uncertain distance estimates rather than measured performance.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.tsb.gc.ca/eng/rapports-reports/aviation/2019/a19o0178/a19o0178.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tsb.gc.ca">[gc.ca]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tsb.gc.ca</span><span class="citation-popover-snippet">Transportation Safety Board of CanadaAir transportation safety investigation report A19O0178 - Transportation Safety Board of Canada...</span></span></span>

    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
