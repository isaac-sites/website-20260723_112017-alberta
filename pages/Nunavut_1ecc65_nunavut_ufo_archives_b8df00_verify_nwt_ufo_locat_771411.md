## Introduction

A UFO report labelled simply as **“Northwest Territories”** should not automatically be treated as a [Nunavut]({{ 'what-really-lies-behind-nunavuts-ufo/' | relative_url }}) case. Before 1 April 1999, the Northwest Territories covered both today's Northwest Territories and the land that became Nunavut. As a result, many older Canadian UFO files use an administrative label that no longer matches modern geography. The key task is therefore to verify where the reported event actually occurred before including it in a history of Nunavut sightings.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.canada.ca/en/library-archives/collection/research-help/science-technology/ufos.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: canada.ca">[Canada]</a><span class="citation-popover" role="note"><span class="citation-popover-source">canada.ca</span><span class="citation-popover-title">s UFOs: The search for the unknown</span><span class="citation-popover-snippet">Canada&#x27;s UFOs: The search for the unknown - Canada.caMarch 2, 2026...</span><span class="citation-popover-meta">Published: March 2, 2026</span></span></span>

For researchers, the territorial label is only the starting point. The decisive evidence usually comes from the named community, island, district, map coordinates, flight route or other geographical clues recorded in the original report. Using those details avoids accidentally assigning western Arctic cases to Nunavut or excluding genuine Nunavut sightings that were filed under the former Northwest Territories administration.

## Why the old territorial label is not enough

Most Canadian federal UFO files were created decades before Nunavut became a separate territory. Government departments, police detachments and aviation authorities naturally recorded locations according to the administrative boundaries that existed at the time. A report dated 1975 and marked "Northwest Territories" could refer to communities now located in either territory.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.canada.ca/en/library-archives/collection/research-help/science-technology/ufos.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: canada.ca">[Canada]</a><span class="citation-popover" role="note"><span class="citation-popover-source">canada.ca</span><span class="citation-popover-title">s UFOs: The search for the unknown</span><span class="citation-popover-snippet">Canada&#x27;s UFOs: The search for the unknown - Canada.caMarch 2, 2026...</span><span class="citation-popover-meta">Published: March 2, 2026</span></span></span>

The problem is compounded because many federal documents identify only a broad jurisdiction rather than a precise place. Library and Archives Canada notes that only about half of the digitised UFO documents specify a particular sighting location, meaning researchers often have to reconstruct the location from other details within the file rather than relying on the catalogue entry alone.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.canada.ca/en/library-archives/collection/research-help/science-technology/ufos.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: canada.ca">[Canada]</a><span class="citation-popover" role="note"><span class="citation-popover-source">canada.ca</span><span class="citation-popover-title">s UFOs: The search for the unknown</span><span class="citation-popover-snippet">Canada&#x27;s UFOs: The search for the unknown - Canada.caMarch 2, 2026...</span><span class="citation-popover-meta">Published: March 2, 2026</span></span></span>

For a Nunavut-focused history, this means administrative labels should never be treated as proof of geographical location.

## Checking communities, islands, districts and coordinates

The most reliable approach is to work from the smallest geographical detail available rather than the territorial heading.

A practical verification sequence is:


<div class="content-enhancement content-enhancement--step-flow" markdown="1">

1. **Identify every named place** in the original report, not just the catalogue description.
2. **Check whether that place now lies within Nunavut** using an authoritative Canadian gazetteer.
3. **Confirm historical names** because many communities have been renamed or standardised since the report was filed.
4. **Compare any recorded latitude and longitude** with modern maps.
5. **Only then classify the report** as belonging to Nunavut or the modern Northwest Territories.

</div>

Natural Resources Canada's Canadian Geographical Names Database is particularly valuable because it allows searches by official name, historical name, feature type and coordinates, making it possible to match older reports with present-day geography. It also records formerly approved names alongside current official ones.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://natural-resources.canada.ca/maps-tools-publications/tools-applications/canadian-geographical-names-database" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: natural-resources.canada.ca">[Natural Resources Canada]</a><span class="citation-popover" role="note"><span class="citation-popover-source">natural-resources.canada.ca</span><span class="citation-popover-title">Natural Resources Canada Canadian Geographical Names Database</span><span class="citation-popover-snippet">Natural Resources CanadaCanadian Geographical Names Database - Natural Resources Canada...</span></span></span>

This matters because older reports may use names that no longer appear on modern road maps.

Examples include:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* **Frobisher Bay**, now **Iqaluit**, in Nunavut.
* Historical territorial districts whose names no longer correspond to current administrative boundaries.
* Older spellings or English versions of northern place names that have since been standardised.

</div>

A report mentioning one of these places may clearly belong to Nunavut even though the territorial heading reads "Northwest Territories."

## Historical districts can be more useful than the territory name

Some reports identify a district rather than a settlement.

Before Nunavut's creation, the eastern Arctic formed part of historical districts such as **Baffin**, **Keewatin** and **Franklin** within the Northwest Territories. These district names often provide stronger evidence than the territorial heading itself because they point towards a particular region of the former territory.

However, even district names deserve careful checking. Administrative boundaries changed over time, and district terminology evolved before the 1999 territorial division. The safest practice is to compare the district named in the report with historical maps and official geographical records rather than assuming a modern equivalent.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://natural-resources.canada.ca/maps-tools-publications/tools-applications/canadian-geographical-names-database" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: natural-resources.canada.ca">[Natural Resources Canada]</a><span class="citation-popover" role="note"><span class="citation-popover-source">natural-resources.canada.ca</span><span class="citation-popover-title">Natural Resources Canada Canadian Geographical Names Database</span><span class="citation-popover-snippet">Natural Resources CanadaCanadian Geographical Names Database - Natural Resources Canada...</span></span></span>

## Handling flight routes and broad Arctic descriptions

Some aviation reports never mention a settlement at all.

Instead, they describe locations such as:


<div class="content-enhancement content-enhancement--phrase-pills" markdown="1">

* "over Baffin Island"
* "north of Hudson Bay"
* "between Yellowknife and Resolute"
* "Arctic Ocean"
* "en route to Frobisher Bay"

</div>

These reports require a different method.

Rather than assigning the entire flight to one territory, identify where the observation actually occurred. Pilots often recorded approximate coordinates, navigation fixes, altitude or elapsed flying time. Even a brief reference to the nearest airport or waypoint can indicate whether the observation happened over present-day Nunavut or elsewhere.

Particular care is needed with flights crossing territorial boundaries. A report may originate from an airport in the modern Northwest Territories while describing an observation over Nunavut airspace, or vice versa. The filing office is not necessarily the sighting location.

Similarly, descriptions such as "Eastern Arctic" or "Canadian Arctic" are geographical regions rather than administrative boundaries. They should be treated as descriptive language until additional location evidence is found.

## Common mistakes when classifying reports

Several recurring errors can distort provincial and territorial UFO histories.


<div class="content-enhancement content-enhancement--caution" markdown="1">

* **Using the filing jurisdiction as the sighting location.** RCMP detachments, military offices or Transport Canada stations often received reports from elsewhere.
* **Ignoring historical place names.** A renamed community may appear to be missing unless older names are recognised.
* **Assuming every pre-1999 Northwest Territories report belongs to the modern Northwest Territories.** Many actually describe places now located in Nunavut.
* **Treating broad regional descriptions as precise locations.** "Eastern Arctic" is not equivalent to Nunavut.
* **Overlooking coordinates.** Latitude and longitude usually outweigh an administrative heading when the two conflict.

</div>

Each mistake can lead to duplicated case lists or incorrectly attributed sightings.

## When the location cannot be confirmed

A transparent classification such as **"Northwest Territories (pre-1999, exact modern territory uncertain)"** preserves historical accuracy while acknowledging the limits of the evidence. This approach avoids inflating Nunavut's historical UFO record with cases that cannot confidently be placed within its present-day boundaries.

        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
